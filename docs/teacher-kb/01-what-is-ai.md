# What is AI?

## The Short Version

AI is software that can read your text and write a response. It is not magic,
not thinking, and not always right. It is a program that learned patterns from
lots of text.

## Key Concepts

### Model

A model is the trained program that reads your input and generates a response.
Think of it as a very large pattern-matching program. Different models have
different strengths and sizes.

**Example:** llama3.2 is a model. GPT-4 is a model. They are different models
made by different companies.

### Prompt

A prompt is the text you send to a model. When you type a question in Squidley,
your question is the prompt.

**Example:** "What is the capital of France?" is a prompt.

### Response

A response is the text the model writes back. It is generated based on patterns
the model learned during training. A response is not a search result — the
model is generating text, not looking things up.

**Example:** "The capital of France is Paris." is a response.

### Hallucination

Sometimes a model confidently says something wrong. This is called a
hallucination. The model is not lying on purpose — it just generates text based
on patterns, and sometimes those patterns lead to incorrect output.

**Example:** A model might claim it wrote a file when no file was written.
Squidley detects these hallucinations and adds a correction.

## Common Misunderstandings

- AI is not sentient or conscious
- AI does not always give correct answers
- AI does not understand things the way humans do
- A bigger model is not always better for simple tasks

## Check Your Understanding

- What does a model actually do with your text?
- Is a model's response always correct?
- What is a hallucination?
