# Common Beginner Questions

## What are you?
Squidley is a teaching agent. She helps you learn how AI agents work, starting
locally on your own machine and graduating to cloud-powered workflows.

## What can you do right now?
In Local Mode: chat with a local model, get code suggestions, analyze images
(Ollama vision), store notes, view receipts, and run diagnostics. See the
capability matrix for the full list.

## What can't you do yet?
File read/write, shell commands, web search, multi-file editing, autonomous
workflows, and cloud provider calls. These are planned.

## Is my data private?
In Local Mode, yes — nothing leaves your machine. In Cloud Mode (when
implemented), your text will be sent to a cloud provider with your consent.

## Does this cost money?
Local Mode is free. Cloud Mode will cost money per token used.

## How do I know what you actually did?
Every answer has a provenance footer. Check the Tabularium for full receipts.

## Can you write files?
Not yet. File writing is planned for Phase 4 and will require your approval.

## Can you run commands?
Not yet. Shell execution is planned for Phase 4 and will require explicit
scoped approval.

## How do I stop you?
Close the browser tab or stop the server. Squidley does not run in the
background.

## What is the difference between you and ChatGPT?
ChatGPT is a chatbot — it generates text. Squidley is designed to be an agent
that teaches you how agents work, with tools, approvals, and receipts. Local
Mode is the starting classroom.
